# nodectl v0.9.0

- 扩展受管入站，支持 VMess、Trojan、Shadowsocks、Shadowsocks-2022、HTTP CONNECT、Mixed 和 Hysteria2。协议、传输、安全层与监听方式按已支持的组合显示。
- 扩展 VLESS、VMess 和 Trojan 的适用传输，提供 gRPC、HTTPUpgrade、mKCP、XHTTP 模式及 VLESS Vision。使用目前锁定的客户端版本时，mKCP 提供 Xray 配置。Trojan 可回落到同一 VLESS Raw TCP + TLS 监听端口，父入站需显式使用外层 TLS。
- 新协议与附加主机沿用设备凭据、分组授权、浏览器登录、按账号流量计量及撤销。HTTP CONNECT 转发 TCP，其余新增组合按支持的协议转发 TCP 和 UDP。
- 设备下载增加完整 Xray 配置、分享链接、二维码及受授权 Hysteria2 的原生配置。现有 Mihomo、Xray 和按比例分流订阅继续可用。
- 增加对应的 VMess、Trojan、Shadowsocks、Shadowsocks-2022、SOCKS5 TLS 和 Hysteria2 出站。出站凭据保存在受保护的密钥文件中。
- 升级沿用当前及上一节点快照。扩展入站需经过配置审批并授予分组权限。
