# nodectl v0.7.0

项目仓库改名为 `node-config-manager`，应用和命令继续使用 `nodectl`。

- 节点页新增浏览器认证。管理员为用户分配独立设备配置，控制认证有效期和同时认证的设备数量。XHTTP、WebSocket、REALITY 及已有配置的节点数量沿用原部署。
- 支持单独和批量创建、删除账号，导入和导出 JSON 用户名单。名单含用户名及设备上限。导入用户使用初始密码 `123456`。
- 运维中心可验签切换程序与对应的 WebUI。支持升级、重新安装和回退，基线为 v0.6.5。可切换的目标须能读取当前及上一节点快照。启用浏览器认证时，版本下限为 v0.7.0。

安装和使用见 [节点浏览器认证](../node-access.md#浏览器认证) 与 [在线版本切换](../installation.md#网页在线切换版本)。
