# nodectl v0.10.0

- 新增 WireGuard、TUIC v5、AmneziaWG、MASQUE CONNECT-IP 和 MTProto 入站。分组授权、浏览器认证、设备上限、账号配额和撤销沿用统一网关。
- 在「客户端」下载经授权的设备配置。TUIC 提供 Mihomo 和 sing-box，AmneziaWG 提供 Mihomo 和原生配置，MASQUE 提供 Xray，MTProto 提供 Telegram 链接和二维码。原生客户端可先用同一设备的浏览器认证配置登录。
- Tunnel 使用明确的来源允许列表和固定目标。TUN 使用专用网络命名空间，按来源和目标网段放行。两种入口经配置事务应用。
- 「节点管理」支持跨节点复制入站、主机、分组定义、出站和路由。审批通过后在目标节点创建禁用草稿。目标节点单独管理凭据、账号和组成员。
- 增加入站到期、流量周期重置、出站链路及轮询组。已生效的快照和计量策略受版本兼容检查保护。

已有节点可直接切换新版后台。新增监听经过「预览 → 检查 → 应用」，原生适配器的安装和 TUN 的接口要求见 [运维手册](../operations.md#可选协议运行时)。
