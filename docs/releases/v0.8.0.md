# nodectl v0.8.0

- 增加主机、入站、客户端和分组管理。新增传输和接入地址需要通过现有配置审阅、检查和应用流程。设备订阅按分组权限追加条目，Mihomo 按协议合计使用已应用的权重。
- 客户端支持暂停、到期时间、已认证设备和活动连接状态、上下行计量、共享总量配额及清零。计量口径为认证中继的传输字节，跨进程重启保存。
- 新增独立配对的多节点管理、SOCKS5、HTTPS CONNECT、VLESS TLS 出站和有序路由。新增业务路由应用在认证后的流量上，现有 CN DNS 和防泄漏规则优先。
- 后台增加页面搜索、面板设置、Xray 配置和 API 文档。版本切换会检查当前及上一配置快照和运行中的账号限制。升级直接沿用 v0.7.4 的配置及客户端身份。
