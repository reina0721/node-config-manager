# nodectl v0.13.1

- 修复旧版节点快照校验，保留历史模板的原始操作清单。生产升级使用本版。
- 共享客户端按需生成配置。首次浏览器认证成功后自动登记设备，并计入账号设备上限。
- 移除手动准备安装名额。已有设备、订阅地址和认证会话继续有效。
- 后台展示设备码、最近认证时间、可信代理入口观测的公网 IP、大致归属地，以及浏览器和订阅客户端上报的系统与版本。
- 升级现有节点后，重新应用同一份节点配置以启用可信 Nginx 来源 IP。模板迁移会短暂重启 Nginx 与 Xray。
- TUIC 和 HTTP/Mixed 附加入站仍缺少在线凭据更新。已有设备继续使用这些入站。附加这些入站的新安装在自动激活时会提示无法激活。
