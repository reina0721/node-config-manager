# nodectl v0.8.2

- 新增 VLESS Raw TCP + TLS 和 Raw TCP + REALITY 独立入站。表单分别显示协议、传输、安全层和监听方式，并按所选组合校验路径与端口。旧版 REALITY 入站继续使用原 XHTTP 配置。
- 新入站通过现有配置审批与分组授权开放。设备的 Mihomo 和 Xray 配置包含获授权的入口，流量继续执行浏览器认证、用量计量和撤销。现有三条入口及客户端凭据沿用原配置。
- 入站校验错误显示在相关字段旁。可以从审批返回编辑草稿。窄屏设备列表可直接下载配置，账号表单在提交前校验用户名、密码和设备上限。
- 签名升级可读取现有当前与上一快照。应用新版配置生成新快照后，运维中心会显示读取该快照所需的版本下限。
